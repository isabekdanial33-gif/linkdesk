LinkDesk 0.1 Preview

Windows EXE, Android/Android TV APK and macOS APP inside ZIP (Apple Silicon and Intel).

Download directly from https://linkdesk-remote.vercel.app. iPhone PWA: https://linkdesk-ios.vercel.app.

Local consent, one-time password, encrypted screen/control, direct connection and relay fallback. Separate native workspace UI without download buttons. TV viewing/remote/Mix layouts.

This is a test release. Windows screen transfer, native text input and session revocation were exercised locally. Android and Mac installers were built; physical Android, TV, iPhone and Mac compatibility is not yet validated. Samsung Tizen/LG webOS receivers and exact original model-specific remotes are not implemented. OS protected surfaces may be unavailable. No audio or dedicated file channel. Desktop binaries are not vendor-notarized. See the installation guide and SHA256SUMS.txt.
